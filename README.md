# To-Do App 📋

Una aplicación simple para gestionar tu lista de tareas diarias.

## Características

- ✅ Agregar nuevas tareas
- ✅ Marcar tareas como completadas
- ✅ Ver todas las tareas en una lista
- ✅ Eliminar tareas
- ✅ Almacenamiento local (las tareas se guardan en tu navegador)

## Cómo usar

1. Abre `index.html` en tu navegador
2. Escribe una tarea en el campo de texto
3. Presiona "Agregar" o Enter para añadir la tarea
4. Marca las tareas completadas con el checkbox
5. Elimina tareas con el botón "Eliminar"
